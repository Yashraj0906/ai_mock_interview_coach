# Case Analysis Interview Scoring Rubric

Use this rubric to evaluate case study and analytical problem-solving answers on a 1-5 scale.

## Dimensions

### 1. Clarity Score (1-5)
- **1 — Poor:** Answer is disorganized. No clear framework or structure to the analysis.
- **2 — Below Average:** Some structure but jumps between points. Hard to follow the reasoning chain.
- **3 — Average:** Reasonable structure but could be tighter. Analysis is followable but not elegant.
- **4 — Good:** Well-structured analysis with clear framework. Logical flow from problem → analysis → recommendation.
- **5 — Excellent:** Exceptionally structured. Uses a clear framework, signposts thinking, and delivers a crisp recommendation.

### 2. Depth Score (1-5)
- **1 — Poor:** Surface-level analysis. Jumps to a conclusion without examining factors.
- **2 — Below Average:** Considers 1-2 factors but misses obvious dimensions of the problem.
- **3 — Average:** Considers multiple factors but analysis lacks rigor. Some assumptions unstated.
- **4 — Good:** Thorough analysis. Considers multiple dimensions, states assumptions, and discusses trade-offs.
- **5 — Excellent:** Comprehensive analysis. Considers second-order effects, quantifies where possible, stress-tests assumptions, and discusses risks.

### 3. Analytical Rigor (1-5)
- **1 — Poor:** No analytical framework. Relies on gut feeling or unsupported assertions.
- **2 — Below Average:** Attempts structure but framework is incomplete or misapplied.
- **3 — Average:** Uses a reasonable framework. Makes logical arguments but some gaps in reasoning.
- **4 — Good:** Strong analytical framework. Data-driven where possible. Clear cause-and-effect reasoning.
- **5 — Excellent:** Rigorous analysis. Quantifies impact, uses appropriate frameworks, considers counter-arguments, and provides actionable recommendations with clear next steps.

### 4. Overall Score (1-5)
Holistic assessment:
- Does the candidate think structurally or just react?
- Are assumptions stated and reasonable?
- Is the recommendation actionable and well-supported?
- Does the candidate show business acumen and strategic thinking?

## Recommendation Logic
- **overall_score < 3** → recommendation: "probe_deeper" — break the problem down or offer a framework hint
- **overall_score == 3** → recommendation: "probe_deeper" on the weakest dimension
- **overall_score >= 4** → recommendation: "increase_difficulty" or "move_on"
